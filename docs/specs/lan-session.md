# 局域网会话

对应 `session-protocol` 的 `lan-session`。设备 id、配对、信标和路由表已有测试。QUIC 连接本身见通道任务，当前运行时还没有 `libmsquic`。

## 设备 id

设备 id 是 `ca1` 加上 SPKI 的 SHA-256 前 16 字节的 26 位小写、无填充 Base32（RFC 4648）。比较大小时用这 16 字节的无符号大端整数。短码是两个 SPKI 按这个顺序排列后做 SHA-256，取前 30 位，编成 6 个小写 Base32 字符。短码不放进任何帧。

叶子证书必须是 ECDSA P-256（OID `1.2.840.10045.3.1.7`）。不看证书日期。id 相同但 SPKI 不同则关闭会话，信任项保留。

## 配对

两边都立刻发出 HELLO，不等对方。HELLO 带意图和显示名。去重保留摘要更大的那一侧打开的会话，另一侧关闭。短码只在留下的会话上计算。双方都发出 `PAIR_ACCEPT` 之后才写入信任，默认剪贴板同步关、保存前询问开。信任之前不发 `PATH_ANNOUNCE`。配对过程中改名不是第二条 HELLO。已经信任之后，显示名不同则发 `DISPLAY_NAME`。60 秒超时或一次拒绝都不写信任。

## 信标和路由

信标魔数 `CA01`，版本 1，后面是 16 字节摘要、大端端口、大端总长度和 UTF-8 显示名。总长度必须等于数据报长度。本机自己的摘要被忽略。显示名不在 1 到 64 个标量之内，或含小于 U+0020 的字符时，路径保留，名字丢掉。

发现路径满 3 分钟过期。过期不删除信任。会话观察到的地址在关闭之后不再拨号。通告地址最多 8 个。链路本地地址（`169.254.0.0/16`、`fe80::/10`）和不在本机前缀上的地址被忽略。未信任的对端只有在 `StartPairing` 之后才拨。某次拨号失败后，要等该候选的 `RefreshedAt` 变化才再拨。
