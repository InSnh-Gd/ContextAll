# 共享效果放在一个模块里

状态：已接受

桌面守护进程和 Android 应用都要应用一次决策、写 QUIC、写文件分段。发现、剪贴板捕获和文件路径随平台不同，而且只有桌面守护进程监听本地客户端。把这段共享工作复制进两个可执行文件，协议修复就要改两处。把这段工作放进决策模块或协议模块，会让那两个模块持有套接字和文件。

`ContextAll.Effects` 只引用决策模块。它运行决策、QUIC 写入和文件分段写入。桌面守护进程和 Android 应用是两个适配器，由它们提供发现、剪贴板捕获和路径。Android 界面调用一个方法，该方法进入这个共享模块。不为这些随平台不同的调用再加第三个共享 IO 项目，因为那些调用不是同一份代码。
