# 文件通过传输到达对端

状态：已接受

文件只作为发给一个已信任对端的传输到达另一台设备。发送方提出该文件。在操作者关闭之前，对端保持「保存前询问」。每个对端同时只有一个出站传输和一个入站传输。文件按 64 KiB 分段，每一段有自己的 SHA-256。接收方保存已落盘分段的位图；断开之后，发送方只传送缺失的段。完成后的字节放进接收方的下载目录，文件名经过清理。

剪贴板是纯文本寄存器，最多 1 MiB。图像不进入该寄存器。复制的文件在本机是路径或 content URI，这个位置在另一台设备上不存在，所以剪贴板不能交出一份可粘贴的文件。文件字节、目录和剪切操作走上面的传输路径。该路径已经有槽位限制和「保存前询问」开关。

若以后增加 PNG 剪贴板寄存器，再重新看「图像不进剪贴板」这一条。那种情况下文件仍然走传输路径。
