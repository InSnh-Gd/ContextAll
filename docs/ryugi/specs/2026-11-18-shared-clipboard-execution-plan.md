# 三端共享剪贴板执行计划

三点交付：这份执行计划和 [Android 后台采集交接](2026-11-18-kdeconnect-clipboard-research.md)。工作在既有独立 worktree 中进行，遵循[已确认设计](2026-11-18-shared-clipboard-design.md)。下面是开发顺序，不是三点前完成功能的承诺。

## 当前实现与验收边界

- Linux 方案已编译，.NET 测试 226 项通过；组内附件中转、来源保留、离线补历史、组外隔离与撤权由双工流集成用例覆盖，另已验证 MsQuic 回环单流。尚未完成三端真实网络联调。
- Win11 虚拟机的 WinUI 构建无警告或错误，8 项定向测试通过。控制台会话中用独立进程验证文本和单文件读写。Android x86_64 原生调试包构建成功、JVM 单测 15 项通过，API 37 模拟器验证历史入口和开关保存；后台接收粘贴、跨平台 PNG 粘贴仍待实测。
- 组采用组主中转，成员分别与组主配对、邀请和确认。组主用直连会话身份验证原始发送者，再保留其设备 ID 转发。成员信任已选的组主，暂不支持任意成员多跳或端到端事件签名。
- 文本限 1 MiB，PNG 或单文件限 10 MiB。重连对最近最多 32 条合格历史重新传输完整条目，不续传已收的部分。组历史限 256 条，默认保留 7 天，可调为 1–30 天；重连的补发受发送队列上限约束。
- 敏感标记命中时一律跳过，不读出给同步引擎。敏感内容的逐次确认、仅在线同步暂未开放。Android 前台自动采集默认关闭，首次引导可选择；后台自动采集仍挂起。
- Windows 和 Linux 提供可置顶的历史窗口。Android 提供应用内历史、快捷设置磁贴和通知入口；Gboard 及其他输入法的历史面板不在应用控制范围内，尚未验收。

## 1. 接通系统纯文本剪贴板

- [ ] **Windows，先做。** 在 `ContextAll.Host` 增加当前用户桌面会话的系统剪贴板后端，订阅外部复制并读写 Unicode 文本。守护进程选择 Windows 后端；没有可用桌面时报告不可用，配对和文件传输继续。验证其他应用有焦点时复制、接收后可粘贴、空文本清空及无自回声。
- [ ] **共享写入与 Linux。** 在 `ContextAll.Session` 把远端寄存器更新与系统写入成功区分开，确认后才持久化 `appliedText`。保留 Wayland、X11 回退和无图形后端降级；验证写失败不会误记成功，旧写入确认也不会覆盖更新状态。启动时保留用户停机期间复制的新内容。
- [ ] **Android 接收。** 让 `LinkService` 持有接收链路，界面离开后仍能写系统剪贴板；普通安装保留有焦点时采集和显式发送，不加后台采集开关。验收桌面发来的普通文本可在手机直接粘贴；Gboard 面板点选另做实测，不以系统写入成功代替。

阶段出口：先跑 `ClipboardRulesTests`、主机后端测试和 Native 桥接测试，再分别用 Windows、Linux 和 Android 的系统剪贴板验证。未拿到 Windows 或真实桌面证据时，单独标注而不是视为通过。

## 2. 接通设备组与文本历史

- [ ] **组与中转。** 在现有身份和 QUIC 会话上增加显式入组、退出、授权和能力协商。用组、原始设备和事件序号识别条目，并验证原始来源；中转不改来源。组外设备收不到，旧逐对通道不重发组内事件。使用三节点和组外第四节点测试中转、去重、撤权和旧版兼容。
- [ ] **历史与补齐。** 保留并发产生的不同条目，当前剪贴板只应用最新有效值。重连只补入组后、仍在保留期内的历史，不逐条写入系统剪贴板。默认保留 7 天，可调整；到期立即停止展示和补发。三端每日清理私有缓存，错过则启动或恢复时补做，保护现有剪贴板和进行中的读取或传输。
- [ ] **隐私与入口。** 只使用来源或系统标记；敏感内容按用户选择实时处理，但不持久化、不离线补发。通过桌面本地通道和 Android JNI 提供历史列表。三端历史「复制」仅本机，「同步到组」独立触发；桌面悬浮入口和 Android 磁贴、通知复用同一面板数据。

阶段出口：以 A→B→C 测试来源和离线补齐，补测并发复制、到期、敏感条目不落盘以及历史复制不广播。Windows、Linux 与 Android 分别验证历史入口；锁屏不展示正文。

## 3. 最后接入图片与单文件

- [ ] **传输。** 从系统提供的图像或文件格式取真实字节；图片和单文件每项暂限 10 MiB，文本仍为 1 MiB。分段写入私有临时文件，以长度和摘要确认完整后再公开为可复制，复用已有的分段和续传机制。超限、半截内容与迟到旧条目不得改写当前剪贴板。
- [ ] **粘贴与离线复用。** 接收端按本机格式发布图片或文件引用。三端两两双向验证截图粘成图、PDF 粘成原文件，并验证来源离线、接收端重启后仍能从历史再次复制。测试 10、25、50 MiB 的延迟、内存、中转与磁盘占用，再决定是否提高上限。

## 挂起与发布边界

Android **后台自动采集**由后续专项接手。本轮不继续查授权，不修改手机权限或输入法，也不把手动发送当成自动采集。Android 接收、前台读取、历史和粘贴按各自的验收继续。其余功能可以独立开发、测试与演示；正式发布前，后台自动采集的原验收条件仍需通过或由用户明确改范围。
