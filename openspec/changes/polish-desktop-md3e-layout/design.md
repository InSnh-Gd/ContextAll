# Design

## Context

这是 `docs/ryugi/specs/2026-11-15-md3e-ui-overhaul-design.md` 的后续设计。以下七项以画板 `artboard/md3e-ui-overhaul`（本地 `.ryugi/artifacts/artboard/md3e-ui-overhaul/canvas.json`）的提交及批注为准。下表足以在没有本地画板的检出中实施。延续零账号局域网设备互联的工作流程、桌面动态取色、固定 96dp 导航、48dp 集成标题栏和真实品牌标；最显眼的动态内容仍是配对短码与传输进度。

## Goals / Non-Goals

让用户在没有设备时有下一步、在不同窗口宽度下能处理同一组任务，并读清设置和当前窗口状态。只调整共享 Avalonia 界面；不改配对、广播、传输队列、持久化与平台装饰协商的语义。预览中的设备名、地址、示例记录、状态数字以及模拟开关均不是产品数据。

## Decisions

| 画板选择 | 实施决定 |
| --- | --- |
| 设备空态 A `empty-guided` | 已连接 Daemon、已信任与待配对列表都为空时，左侧继续显示发现状态、局域网状态与一个全局剪贴板入口；宽屏右侧说明同网、打开另一端、核对真实短码，并链接既有手动连接页。出现设备但未选中时恢复选择提示，选中则显示详情。窄屏将必要说明和连接入口放入列表空态，不挤出第二栏。服务未连接时使用已有服务状态提示，不声称正在发现。 |
| 连接 B `connection-shell-aligned` | 使用窗口宽度：≥840dp 左拨号、右网络信息，28dp 圆角画布，间隔 12dp；更窄时先拨号后网络信息。保留页眉剪贴板状态、使用指南、预设和反馈。地址及备注按用户参考图：四角圆润、完整细描边、内边距、始终可见的标签；画稿为高 56dp、圆角 20dp。以现有焦点、错误与动态取色角色表达状态，不使用仅底部指示线。该决定针对这两个字段，不批量改写其它表单。 |
| 本机设置 B `device-settings-split` + 窄屏 A `device-settings-single` | 宽屏左侧列出本机身份、外观与主题、文件与后台、窗口、帮助，右侧仅编辑当前分类；窄屏同序显示五组，最大宽度 640dp，可滚动。断点 **840dp 是实施默认值**，宽 B 窄 A 是用户批注。分类为临时视图状态，不写 Shell 偏好。 |
| 阅读优先 A `density-readable` | 设置名称 16sp、说明 14sp、行最小 72dp。长中文及等宽标识可换行；字号使用与现有 MD3E 字阶对应的主题角色。 |
| 分组 A `surface-tiles` | 每组行间距 2dp、无描边，整组外角 24dp、内部相邻角 6dp；单行组四角均为外角。不改变行内连接按钮组的形状。 |
| 传输 A `transfer-totals-history` | 保留 `g2-split-workbench` 左投递、右队列与现有响应式堆叠、接收操作和波浪进度。把现有三项累计统计移到传输记录之后，空记录也保留统计；不再占用页首，不重新计算数据。 |
| 标题栏 A `chrome-current` | 标题为「优先使用系统标题栏」；开关代表偏好，说明代表结果。关闭时「正在使用应用标题栏。」；协商成功时「正在使用系统标题栏。」；开启但回退时「当前桌面未提供系统标题栏，正在使用应用标题栏。」。等待协商时不提前宣告成功或不支持。 |

`ShellLayout.TwoColumns` 已以窗口为参照。由外壳传递同一判定给连接与本机页，避免页面再对扣除导航宽度后的值判断。调整布局时复用同一 ViewModel、命令与绑定；不得丢失地址/备注草稿、打开的编辑对话框或重复订阅事件。设备页手动连接走现有导航请求，剪贴板仍说明广播范围。

标题栏的真实结果来自 `MainWindow.ApplyChromeMode` 的装饰协商，经 `ShellRootView.ApplyChrome` 传给设置页。只持久化用户偏好，不持久化运行时结果，不按桌面环境名猜测状态。没有系统装饰就沿用应用页眉，不叠加第二组窗口按钮。

这里的「成功」指外壳按现有判断采用系统装饰模式，不要求合成器提供新的确认事件。`_nativeDecorationsSettled` 为假且请求仍在进行时，说明保持待定；结束后读取同一次 `ApplyChromeMode` 的 `systemTitleBarActive`，后续装饰变化时同步刷新。运行时开启与启动时开启应经过同一判断，不能因为偏好已写入而漏掉状态更新。

## Risks / Trade-offs

- 现有 `md3e-ui-overhaul` 已勾选的任务仍描述旧实现；此变更只覆盖上表涉及的后续决定，不重开或归档旧变更。`device-shell` 已是主规格中的能力，delta 增加桌面详细约束。
- 设置分栏额外占宽。在最小 480×640、839/840dp 临界宽度与 1280×800 检查长文案、按钮、键盘焦点和滚动。桌面版共享组件也被 Windows 使用，不复制另一套布局、不触碰平台宿主。
- 无头测试可覆盖装饰状态映射，但不能代替合成器实际渲染。用 GNOME/Wayland 检查回退，有可提供系统装饰的环境时检查成功分支；无此环境时明确区分模拟验证与实机验证。
